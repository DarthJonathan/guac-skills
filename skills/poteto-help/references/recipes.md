# Recipes

- Bug: $poteto-mode Reproduce this failure, find its mechanism, fix it, and verify the user path.
- Design: $architect Compare two ownership models for this state before implementing.
- Review: $interrogate Review this branch against its actual base and explain proven failure cases.
- Performance: $poteto-mode Measure the current cost, inspect a trace, improve it, and compare under the same workload.
- Catch-up: $recall Rebuild the current state of my work on this topic in this project.
- Proof: $create-verification-skill Build a project-local way to drive the real application.
- Parallel coverage: $swarm Check each package using its documented validation command and report every missing result.
