# Prompting pstack in Codex

Invoke $poteto-mode with the desired behavior, relevant files or PR, constraints, and an observable done condition. State checkpoints, model choices, or publishing permission only when you want them.

Example: $poteto-mode Fix the duplicate-save bug. Reproduce it locally, preserve the API, and show the behavior after the fix.

Use $interrogate to request a review, $architect to compare interface shapes, or $how to understand the system first. Skills inherit the host model. A multi-model comparison needs supported models you explicitly choose.
